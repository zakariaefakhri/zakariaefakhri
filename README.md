#### Machine learning and AI

#### Algorithms

- [huffman-coding](https://github.com/zakariaefakhri/huffman-coding): Huffman compression with its own min-heap and bit packing.
- [dijkstra-shortest-paths](https://github.com/zakariaefakhri/dijkstra-shortest-paths): Dijkstra with all shortest-path predecessors.
- [kruskal-mst](https://github.com/zakariaefakhri/kruskal-mst): Kruskal with union-find and merge sort.
- [bfs-maze-solver](https://github.com/zakariaefakhri/bfs-maze-solver): shortest path through a grid maze with BFS.
- [hybrid-graph-crypto](https://github.com/zakariaefakhri/hybrid-graph-crypto): a toy cipher built on random graphs and tree traversals. Educational only.
